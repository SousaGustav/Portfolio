Política de Privacidade

Última atualização: 21 de junho de 2026

Esta política explica, de forma simples, como os dados de quem visita ou entra em contato por este site são tratados. Não é um texto genérico copiado de modelo — reflete como este site realmente funciona.

1. Quem trata os dados

Este site é mantido por Gustavo Sousa, desenvolvedor front-end independente, com contato pelo e-mail joaogustavocostadesousa@gmail.com.

2. Quais dados são coletados

Este site não possui formulário de cadastro, login ou área de usuário. Os dados que podem ser tratados são:

  • Dados de contato voluntário: quando você escolhe falar via WhatsApp, e-mail ou LinkedIn, os dados que você mesmo compartilha nessa conversa (nome, telefone, descrição do projeto) ficam armazenados na própria plataforma usada (WhatsApp, Gmail, LinkedIn), não neste site.
  • Dados de navegação: informações técnicas básicas de acesso (como tipo de dispositivo e páginas visitadas) podem ser coletadas pela plataforma de hospedagem (ex: Vercel, Netlify) para fins de funcionamento e estatística do serviço.

3. Cookies

Este site não utiliza cookies próprios de rastreamento, login ou publicidade. A plataforma de hospedagem pode utilizar cookies técnicos essenciais ao funcionamento da infraestrutura.

4. Como os dados são usados

Os dados compartilhados voluntariamente em contato (WhatsApp, e-mail, LinkedIn) são usados exclusivamente para responder sua mensagem, elaborar orçamentos e conduzir o projeto contratado. Eles não são vendidos, compartilhados com terceiros para fins de marketing ou usados para qualquer finalidade diferente da comunicação com você.

5. Compartilhamento com terceiros

Os dados podem transitar pelas plataformas usadas para comunicação e hospedagem (Meta/WhatsApp, Google, LinkedIn, Vercel, Netlify, GitHub), cada uma com sua própria política de privacidade. Fora isso, nenhum dado é repassado a terceiros.

6. Seus direitos

Conforme a Lei Geral de Proteção de Dados (LGPD), você pode, a qualquer momento, solicitar:

  • Confirmação de quais dados seus foram armazenados em conversas anteriores;
  • Correção de dados incorretos;
  • Exclusão de dados de contato armazenados (ex: histórico de conversa de WhatsApp ou e-mail);
  • Informações sobre o uso desses dados.

Pra exercer qualquer um desses direitos, basta enviar uma mensagem pelo e-mail de contato.

7. Segurança

Como a comunicação acontece por plataformas de terceiros (WhatsApp, Gmail, LinkedIn), a segurança dos dados durante a conversa segue os padrões de segurança dessas próprias plataformas.

8. Alterações nesta política

Esta política pode ser atualizada conforme o site evolui. A data da última atualização está sempre indicada no topo desta página.

9. Contato

Dúvidas sobre esta política podem ser enviadas para joaogustavocostadesousa@gmail.com.
